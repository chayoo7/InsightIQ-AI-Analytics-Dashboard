# InsightIQ — AI-Powered Analytics Dashboard

## Project Overview

InsightIQ is a Python based business analytics dashboard designed to explore sales performance through interactive data visualizations.

The project is being developed into an AI-powered analytics platform featuring natural language data exploration, automated business insights, and machine learning based forecasting.

## Current Features

- Sales and profit KPI tracking
- Interactive sales and profit trend visualization
- Tabular sales data exploration
- Streamlit powered web interface

## Technology Stack

- **Python** — Application development and data processing
- **Pandas** — Data analysis
- **Plotly** — Interactive data visualization
- **Streamlit** — Dashboard interface

## Getting Started

Clone the repository and navigate to the project folder.

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
